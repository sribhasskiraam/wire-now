# Instructions for AI assistants

Before doing anything on this project, read **[MASTER_INDEX.md](MASTER_INDEX.md)**. It explains what Wire Now is,
how every part works, the owner's rules and decisions, and what is planned.

Rules:
1. Follow the owner's ground rules in section 2 of the Master Index.
2. After any change, update the Master Index (the matching section and the decision log) in the same commit.
3. This repository is public: never commit passwords, keys, tokens, emails or personal details.
   Secrets go only in GitHub → Settings → Secrets.
4. Test before pushing: the robot runs every 15 minutes on GitHub Actions, so a broken `bot.py` stops the news.
